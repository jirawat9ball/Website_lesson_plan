ตัวอย่างการใช้งาน CSS Display

1. Display: Block (ค่าเริ่มต้นของ <div>)

กินพื้นที่ความกว้างเต็มบรรทัด (ถ้าไม่กำหนด width) และจะดันให้ element ถัดไปต้องขึ้นบรรทัดใหม่เสมอ

Block 1 (ตัวถัดไปต้องขึ้นบรรทัดใหม่)
Block 2

2. Display: Inline (ค่าเริ่มต้นของ <span>)

กินพื้นที่ความกว้างเท่าที่จำเป็นตามเนื้อหาข้างใน ไม่ขึ้นบรรทัดใหม่ และไม่สามารถกำหนดความกว้าง (width) หรือความสูง (height) ได้

Inline 1 (สั่งกว้าง 500px แต่ไม่เป็นผล) Inline 2 (เรียงต่อกันในบรรทัดเดิม)

3. Display: Inline-Block

คุณสมบัติผสม คือเรียงต่อกันในบรรทัดเดิมได้ (เหมือน inline) แต่สามารถกำหนดความกว้าง (width) และความสูง (height) ได้ (เหมือน block)
