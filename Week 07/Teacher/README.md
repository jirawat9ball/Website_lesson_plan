### 1. 🎨 ส่วนที่ 1: จิตวิทยาของสีและรหัสสีดิจิทัล (15 นาที)
*   **แนวทางการอธิบายเรื่องการลงสี**:
    *   หน้าจอคอมพิวเตอร์สร้างสีจาก **"แสงของแม่สีทั้ง 3 สี" (RGB: Red, Green, Blue)** รวมกันเป็นแสงสีขาว
    *   **เปรียบเทียบรหัสสี 3 สไตล์**:
        1.  **HEX (#RRGGBB)**: รหัสเลขฐานสิบหก (0-9 และ A-F) เปรียบเสมือน **"พิกัดลับทางทหารของสี"** เช่น `#FF0000` คือ แดงล้วนไร้สีอื่นปน
        2.  **RGB (Red, Green, Blue)**: เปรียบเหมือน **"จานผสมแม่สีของช่าง"** ระบุปริมาณเนื้อสีตั้งแต่ 0 ถึง 255 (เช่น `rgb(255, 0, 0)`)
        3.  **HSL (Hue, Saturation, Lightness)**: เปรียบเหมือน **"แป้นหมุนปรับความรู้สึกจิตรกร"** (Hue = องศาวงล้อสี 0-360, Saturation = เปอร์เซ็นต์ความสดของสี, Lightness = เปอร์เซ็นต์ความมืดความสว่าง)
            *   *ข้อดี*: เป็นรหัสสีที่มนุษย์อ่านและปรับเปลี่ยนจินตนาการได้ง่ายที่สุดเมื่อเทียบกับรหัสอื่น!

### 2. ✍️ ส่วนที่ 2: ฟอนต์สร้างอารมณ์และแหล่งดึงฟอนต์ Google Fonts (15 นาที)
*   **แนวทางการเปรียบเทียบจิตวิทยาฟอนต์ (Typography)**:
    *   ฟอนต์เปรียบเสมือน **"เสื้อผ้าและน้ำเสียงของผู้พูด"**
        *   **Serif (ฟอนต์แบบมีหัว / มีฐานขีด)**: เปรียบเหมือน **"ผู้ใหญ่ในชุดสูทภูมิฐาน"** ให้ความรู้สึกดั้งเดิม น่าเชื่อถือ มีอำนาจ (เช่น Times New Roman, อักษรไทยแบบประดิษฐ์)
        *   **Sans-Serif (ฟอนต์ไม่มีหัว / ไม่มีขีด)**: เปรียบเหมือน **"วัยรุ่นในเสื้อยืดและกางเกงยีนส์"** ทันสมัย สะอาดตา อ่านง่ายบนหน้าจอคอมพิวเตอร์และมือถือ
    *   **Google Fonts**: บริการตู้คอนเทนเนอร์เก็บฟอนต์สาธารณะบนระบบคลาวด์ สอนวิธีการกดเลือกฟอนต์ คัดลอกแท็ก `<link>` แปะลงใน `<head>` และอ้างอิงผ่าน `font-family` ใน CSS

### 🔍 ส่วนที่ 3: เปิดกล่องเครื่องมือลับ Inspect Element (10 นาที)
*   **แนวทางการสอน**:
    *   ครูสอนกดปุ่ม **F12** บนคีย์บอร์ด หรือ **คลิกขวา -> ตรวจสอบ (Inspect)** บนเบราว์เซอร์
    *   แนะนำกล่องเครื่องมือของโปรแกรมเมอร์ (Developer Tools) เพื่อแอบดูโค้ดของเว็บไซต์ชื่อดังระดับโลก และทดลองแก้เปลี่ยนสีฟอนต์เล่นบนหน้าจอทันที (เน้นย้ำความขี้เล่น: "นี่เป็นการแก้ไขชั่วคราวในเครื่องเราเพื่อทดลองเฉยๆ พอกดรีเฟรชหน้าจอก็หายหมดนะ ไม่ใช่การแฮกเกอร์ระบบหลังบ้านของเขาจริงๆ!")

### 4. 🧠 ส่วนที่ 4: กิจกรรมทดสอบความเข้าใจด่วน (Quick Quiz) (5 นาที)
เช็กความพร้อมด้วย 3 คำถามด่วน:
1.  **คำถาม 1**: หากต้องการสีที่ดูพาสเทล (สว่างสดใสแต่อ่อนนุ่ม) การใช้รหัสสีใดระหว่าง HEX, RGB, HSL จะอำนวยความสะดวกในการปรับแต่งให้สว่างขึ้นได้ง่ายที่สุด? *(แนวตอบ: HSL เพราะแค่หมุนตัวเลข Lightness ไปแถวๆ 80-90% ก็จะได้สีโทนสว่างพาสเทลทันที)*
2.  **คำถาม 2**: เว็บไซต์ข่าวสารที่เป็นทางการและต้องการความน่าเชื่อถือสูงมากๆ ควรพิจารณาเลือกใช้ฟอนต์ตระกูลใดเป็นหลัก? *(แนวตอบ: Serif)*
3.  **คำถาม 3**: เครื่องมือ "Inspect Element" (คลิกขวา -> ตรวจสอบ) มีประโยชน์ต่อการเรียนรู้การเขียนเว็บอย่างไรบ้าง? *(แนวตอบ: ช่วยให้จำลองทดลองเปลี่ยนสี ขนาดตัวอักษร หรือสไตล์ของโค้ดดูได้ทันทีโดยไม่ต้องไปแก้ไฟล์จริง แล้วค่อยนำค่าที่ชอบกลับไปบันทึกลงในไฟล์โค้ด)*


## ⏱️ แผนจัดสรรเวลาสำหรับคาบปฏิบัติ Workshop (90 นาที)

**โจทย์หลัก (Main Task):** ให้นักเรียนสร้างหน้าเว็บ "แนะนำเมนูอาหารสุดโปรด" หรือ "ตัวละครในดวงใจ" โดยใช้ **Typography (ฟอนต์)** และ **Color Theory (ทฤษฎีสี)** เป็นเครื่องมือหลักในการดึงอารมณ์ความรู้สึกของผู้เข้าชมให้อินไปกับเนื้อหา!

### 📅 รายละเอียดกิจกรรม (Step-by-Step):

#### 1. วางโครงร่างและเตรียมความพร้อม (15 นาที | 10:40 - 10:55 น.)
*   **สร้างไฟล์พื้นฐาน:** ให้นักเรียนสร้างโฟลเดอร์โปรเจกต์ใหม่ ประกอบด้วยไฟล์ `index.html` และ `style.css`
*   **เขียนโครงสร้าง HTML:** 
    *   ใช้แท็ก `<h1>` สำหรับชื่อเรื่องหลัก (เช่น ชื่อเมนู หรือ ชื่อตัวละคร)
    *   ใช้แท็ก `<h2>` สำหรับหัวข้อย่อย (เช่น วัตถุดิบ หรือ พลังความสามารถ)
    *   ใช้แท็ก `<p>` อย่างน้อย 2 ย่อหน้าสำหรับบรรยายสรรพคุณและความรู้สึก
    *   สร้างกล่อง `<div>` สำหรับจัดกลุ่มเนื้อหาเพื่อเตรียมตกแต่งในขั้นต่อไป
*   **เช็คความเข้าใจ:** ครูเดินดูรอบห้องเพื่อตรวจสอบว่านักเรียนลิงก์ไฟล์ `<link rel="stylesheet" href="style.css">` ถูกต้องหรือไม่ก่อนเริ่มลงสี

#### 2. ศิลปะแห่งฟอนต์ด้วย Google Fonts (20 นาที | 10:55 - 11:15 น.)
*   **ภารกิจเลือกฟอนต์:** ให้นักเรียนเข้าเว็บไซต์ [Google Fonts](https://fonts.google.com/)
*   **กฎการใช้ฟอนต์ (Typography Rule):**
    *   **Heading:** เลือกฟอนต์ 1 แบบสำหรับหัวข้อ (แนะนำกลุ่ม Serif หรือ Display เพื่อดึงดูดสายตา)
    *   **Body:** เลือกฟอนต์อีก 1 แบบสำหรับเนื้อหา (แนะนำกลุ่ม Sans-Serif เพื่อให้อ่านง่ายสบายตาบนหน้าจอ)
*   **ลงมือทำ:**
    *   ให้นักเรียนนำแท็ก `<link>` หรือ `@import` ของฟอนต์ที่เลือกมาใส่ในโปรเจกต์ตัวเอง
    *   เขียน CSS เรียกใช้ `font-family` กับแท็ก `h1`, `h2` และ `p` 
*   **Mini-Challenge:** ลองปรับขนาด `font-size` และความหนา `font-weight` ให้หัวข้อดูโดดเด่นกว่าเนื้อหาอย่างชัดเจน

#### 3. ระบายสีสร้างอารมณ์ด้วย CSS Colors (25 นาที | 11:15 - 11:40 น.)
*   **กำหนด Mood & Tone:** ให้นักเรียนคิดอารมณ์ของหน้าเว็บตัวเอง (เช่น ร้อนแรง, เย็นสบาย, ลึกลับ, น่ารัก)
*   **เล่นกับรหัสสีทั้ง 3 แบบ:**
    *   **พื้นหลัง (Background):** ใช้รหัสสีแบบ **HEX** (เช่น `#FDF6E3`) สำหรับ `background-color` ของหน้าเว็บหรือกล่องเนื้อหา
    *   **สีตัวอักษร (Text Color):** ใช้รหัสสีแบบ **RGB** หรือ **RGBA** สำหรับสีข้อความทั่วไป
    *   **สีเน้นย้ำ (Accent Color):** ให้ลองใช้รหัสสีแบบ **HSL** สำหรับข้อความที่ต้องการเน้น! ครูแนะนำให้นักเรียนลองหมุนปรับค่า Hue (องศาสี) เพื่อหาเฉดสีที่ตัดกับพื้นหลังได้อย่างลงตัว
*   **จุดเน้นย้ำสำหรับครู:** เดินกระตุ้นให้นักเรียนลองใช้สีที่คอนทราสต์กัน (Contrast) ระหว่างพื้นหลังกับตัวอักษร เพื่อให้ยังคงอ่านง่าย

#### 4. แฮกเกอร์จำลอง: เจาะระบบด้วย Inspect Element (15 นาที | 11:40 - 11:55 น.)
*   **ภารกิจจับผิดและปรับแต่ง:**
    *   ให้นักเรียนเปิดหน้าเว็บของตัวเองบนเบราว์เซอร์ แล้วกด **F12** หรือคลิกขวาเลือก **Inspect (ตรวจสอบ)**
    *   ลองใช้เมนู Element ถอดรหัสสีและฟอนต์ที่ตัวเองเขียนไว้
    *   **Live Editing:** ให้นักเรียนลองเปลี่ยนค่าสี หรือเปลี่ยนขนาดฟอนต์บนแถบ Styles ของเบราว์เซอร์สดๆ 
    *   *เคล็ดลับ:* หากค้นพบการจับคู่สีใหม่ที่สวยกว่าจาก Inspect Element ให้นักเรียนคัดลอกค่านั้นกลับไปแก้ในไฟล์ `style.css` ของตัวเอง!

#### 5. สรุปผลงานและแลกเปลี่ยนไอเดีย (15 นาที | 11:55 - 12:10 น.)
*   **Gallery Walk หรือ สุ่มนำเสนอ:** 
    *   ให้นักเรียนหันหน้าจอให้เพื่อนข้างๆ ดู หรือครูสุ่มหน้าจอขึ้นโปรเจกเตอร์ 2-3 คน
    *   **คำถามสะท้อนความคิด (Reflection):** "ทำไมถึงเลือกใช้คู่สีนี้ และฟอนต์นี้สื่อถึงอารมณ์อะไรของตัวละคร/อาหาร?"
*   **สรุปบทเรียน:** เน้นย้ำว่าเครื่องมือ (Code) เป็นเพียงส่วนหนึ่ง แต่ความคิดสร้างสรรค์และการเลือกใช้ศิลปะ (Color & Font) คือสิ่งที่ทำให้เว็บมีชีวิต

*💡 คำแนะนำจากครู: การทำเว็บไม่มีผิดถูกในเรื่องของศิลปะ! ขอแค่ให้ตัวอักษรอ่านง่าย (Good Contrast) และสื่ออารมณ์ได้ตรงตามที่ต้องการก็ถือว่าประสบความสำเร็จแล้ว!*
