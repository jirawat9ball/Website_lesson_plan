# สัปดาห์ที่ 13: คอมโพเนนต์การ์ดและหน้าคอร์สเรียน (Components & Course Page)

## กิจกรรมปฏิบัติ
[Project] หน้าคอร์สเรียนและการ์ดสินค้า (Course Page)

### งานที่ต้องทำ (Core)
* สร้างไฟล์ `course.html` และคัดลอก Navbar / Footer มาจากหน้า Index
* สร้างส่วนรายละเอียดคอร์ส (ซ้าย: รูป, ขวา: ข้อความ, ราคา, และปุ่ม Add to cart สีฟ้า)
* สร้าง HTML สำหรับ "การ์ด 1 ใบ" ประกอบด้วย ภาพ, ชื่อ, ราคา และรายละเอียดสั้นๆ
* ตกแต่งการ์ดด้วย CSS (ให้มีเส้นขอบจางๆ และเงาตกกระทบ `box-shadow`)
* สร้างการ์ดเพิ่มให้ครบ 3 ใบ และใช้ `display: grid;` จัดเรียงการ์ดทั้ง 3 ให้ขนานกันเป็น 3 คอลัมน์ 

### งานเพิ่มเติม (Extra/Review)
* ลองทำเอฟเฟกต์ Hover ให้กับการ์ด (เช่น เมื่อเอาเมาส์ชี้ การ์ดจะขยับลอยขึ้นมาเล็กน้อย หรือเงาเข้มขึ้น)
