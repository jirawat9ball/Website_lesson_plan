# สัปดาห์ที่ 13: Bootstrap Grid & Components (Merged)

## กิจกรรมปฏิบัติ
**[Project] Product Landing Page (หน้าเว็บจำหน่ายสินค้าอเนกประสงค์)**

ในแล็บนี้ นักเรียนจะได้ประกอบสร้างหน้าเว็บโปรโมตและขายสินค้าโดยใช้เฟรมเวิร์กสำเร็จรูป **Bootstrap 5** ผสมผสานระบบตาราง Grid System เพื่อควบคุมสัดส่วนบนจอคอมพิวเตอร์และมือถือ ร่วมกับชิ้นส่วนหน้าเว็บ (Components) และการเขียนสไตล์ทับ (Override CSS) เพื่อสร้างความโดดเด่น

---

### งานที่ต้องทำ (Core Mission)
1. **เชื่อมต่อ Bootstrap CDN**: 
   - นำเข้าลิงก์ Bootstrap 5 CSS ที่ส่วนหัว `<head>`
   - นำเข้าสคริปต์ Bootstrap 5 JS Bundle ที่ส่วนล่างสุดของ `<body>`
   - ลิงก์ไฟล์ `style.css` ส่วนตัวให้ถูกต้อง (วางไว้ใต้ CDN)
2. **สร้างเมนูนำทางและสไลด์โชว์**:
   - เพิ่มแถบเมนูนำทาง (Navbar) ที่หัวเว็บ รองรับระบบพับปิดเปิด (Responsive toggler)
   - เพิ่มสไลด์โชว์ (Carousel) โชว์รูปภาพอย่างน้อย 2 ภาพขยับได้
3. **จัดสัดส่วนการ์ดสินค้า 3 ชิ้น**:
   - ออกแบบระบบกริดแบ่งแถวแนวนอน (`row`)
   - วางการ์ดสินค้า (`card`) จำนวน 3 กล่องเรียงหน้าเท่ากัน
   - กำหนดขนาดให้รองรับ Responsive: จอคอมพิวเตอร์กว้างเรียงเป็น 3 คอลัมน์ (`col-lg-4`), จอแท็บเล็ตเรียงเป็น 2 คอลัมน์ (`col-md-6`), และจอมือถือแสดงผลแถวเดียวนอนยาว (`col-12`)

---

### งานเพิ่มเติมและส่วนท้าทาย (Extra Challenge)
1. **แต่งสไตล์ Override CSS**:
   - แต่งเปลี่ยนแบบอักษร (Fonts) โดยดึงจาก Google Fonts
   - สร้างคลาสปุ่มแบรนด์ส่วนตัวและระบุสีไล่เฉด (Gradient)
   - แต่งเอฟเฟกต์การโฮเวอร์ (Hover Effects) ให้การ์ดสินค้าลอยตัวและมีมิติเงาเมื่อเมาส์ชี้ผ่าน
2. **การทดสอบความถูกต้อง**:
   - ย่อและขยายขนาดของเว็บเบราว์เซอร์เพื่อตรวจเช็คดูการสลับขนาดของกริดสินค้า (Responsive Check) ว่ามีส่วนไหนตกหล่น หรือเลย์เอาต์เบี้ยวพังหรือไม่
