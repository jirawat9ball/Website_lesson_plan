# สัปดาห์ที่ 5: JavaScript Core Fundamentals (Student Lab)

## กิจกรรมปฏิบัติ
**[Project] Rock-Paper-Scissors Game (เกมเป่ายิ้งฉุบสะสมแต้ม)**

ในแล็บนี้ นักเรียนจะได้ประกอบสร้างระบบเกมเป่ายิ้งฉุบต่อสู้กับคอมพิวเตอร์ผ่านเว็บเบราว์เซอร์ เพื่อเรียนรู้โครงสร้างและไวยากรณ์หลักที่จำเป็นต้องรู้ของ JavaScript (Core JS) ได้แก่ **Array, Object, switch-case, การวนลูป (for loop), และการเปรียบเทียบประเภทฟังก์ชัน (Regular vs Arrow)**

---

### งานที่ต้องทำ (Core Mission)

1. **เชื่อมต่อสคริปต์ภายนอก**: 
   * เชื่อมโยงไฟล์ `script.js` เข้ากับหน้าเว็บ `index.html` ที่ด้านล่างสุดของแท็ก `<body>`
2. **จัดระบบตัวแปรสถานะด้วย Object**:
   * ประกาศสถานะสะสมของเกมไว้ในตัวแปรแบบ Object ชื่อ `gameState` ที่มีคุณสมบัติเก็บคะแนนสะสมฝั่งผู้เล่น (`playerScore`), คอมพิวเตอร์ (`computerScore`), และแต้มชนะเป้าหมาย (`winningScore = 5`)
3. **สร้างทางเลือกด้วย Array**:
   * ประกาศ Array ชื่อ `choices` เพื่อเก็บค่าทางเลือกทั้ง 3 ทาง ได้แก่ `'rock'`, `'paper'`, และ `'scissors'`
4. **เขียนฟังก์ชันแปลง Emoji ด้วย switch-case**:
   * เติมฟังก์ชันย่อย `getChoiceEmoji` แบบ Arrow Function โดยใช้คำสั่ง `switch-case` เพื่อทำการจับคู่ทางเลือกภาษาอังกฤษไปเป็นสัญลักษณ์ Emoji ภาษาไทยให้ถูกต้องสมบูรณ์
5. **สร้างตรรกะสุ่มและเปรียบเทียบ**:
   * ในฟังก์ชันหลัก `play()` ให้เขียนระบบสุ่มดึงทางเลือกของคอมพิวเตอร์จาก Array `choices` ผ่านคำสั่ง `Math.random()`
   * เขียนเงื่อนไขเปรียบเทียบ `if-else if-else` ตรวจความแพ้ชนะในรอบนั้นสะสมคะแนนเพิ่มขึ้นไปยัง Object `gameState` และนำผลลัพธ์ไปพิมพ์บอกสถานะหน้าจอจริง
6. **วนลูปผูกปุ่มตัวเลือก (for loop)**:
   * เขียนวนลูป `for` เพื่อทำการดึง Element ปุ่มตัวเลือกทั้ง 3 ปุ่มผ่านไอดี และผูกเหตุการณ์คลิกปุ่ม (`addEventListener`) เพื่อรันฟังก์ชัน `play()` โดยส่งข้อมูลทางเลือกรอบปัจจุบันเข้าไปโดยอัตโนมัติ

### งานเพิ่มเติมและส่วนท้าทาย (Extra Challenge)

1. **ระบบล็อกปุ่มยุติเกมด้วยลูป**:
   * ในฟังก์ชันปิดเกม `declareWinner` ให้เขียนวนลูป `for` เพื่อสั่งปิดสิทธิ์ปุ่มเลือกเป่ายิ้งฉุบทั้งหมด (`disabled = true`) เมื่อแต้มสะสมฝั่งใดฝั่งหนึ่งชนขีดจำกัด 5 คะแนน
   * อัปเดตข้อความสรุปผู้ชนะขั้นสุดท้าย
2. **ระบบคืนค่าเริ่มใหม่ (Reset Game)**:
   * ในฟังก์ชัน `resetGame` เขียนรีเซ็ตคะแนนสะสมใน Object `gameState` เคลียร์ข้อความบนจอภาพ และเขียนวนลูป `for` เพื่อปลดล็อกปุ่มเป่ายิ้งฉุบทั้งหมดกลับมาทำงานอีกครั้ง (`disabled = false`) พร้อมซ่อนปุ่มรีเซ็ต
