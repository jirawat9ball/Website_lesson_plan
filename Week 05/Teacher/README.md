### 1. 📦 ส่วนที่ 1: ตัวแปรแบบโครงสร้างข้อมูล (Array & Object) (15 นาที)
*   **Array (ตัวแปรแบบชุดข้อมูลลำดับ)**:
    *   เปรียบเหมือน **"กล่องใส่ของที่มีช่องแบ่งเป็นช่องๆ และมีหมายเลขกำกับ (Index)"** เริ่มต้นจากช่องที่ 0
    *   นำมาใช้เก็บทางเลือกของเกมเป่ายิ้งฉุบเพื่อสุ่มตัวเลือกคอมพิวเตอร์: `const choices = ['rock', 'paper', 'scissors'];`
    *   เข้าถึงข้อมูลด้วย index เช่น `choices[0]` (ได้ `'rock'`)
*   **Object (ตัวแปรแบบโครงสร้างคู่ Key-Value)**:
    *   เปรียบเหมือน **"แฟ้มประวัตินักเรียนที่มีป้ายระบุชื่อหัวข้อและมีข้อมูลอยู่ข้างใน"** ช่วยจัดเก็บตัวแปรเดี่ยวๆ ที่กระจัดกระจายให้มาอยู่เป็นกลุ่มก้อนอย่างเป็นระบบ
    *   นำมาใช้เก็บสถานะสะสมของเกม (State Object):
        ```javascript
        const gameState = {
            playerScore: 0,
            computerScore: 0,
            winningScore: 5
        };
        ```
    *   เข้าถึงข้อมูลผ่านเครื่องหมายจุด (Dot Notation) เช่น `gameState.playerScore`

### 2. ✊✌️✋ ส่วนที่ 2: ตรรกะเงื่อนไขและลูป (switch-case & for/while) (15 นาที)
*   **switch-case (ตรรกะแบบมีทางเลือกชัดเจน)**:
    *   เปรียบเหมือน **"ตู้ทางแยกที่มีป้ายบอกทางตรงๆ"** ถ้าตรงกับเงื่อนไขใดให้ทำทันที เหมาะกับกรณีที่เปรียบเทียบความเท่ากันแบบระบุค่าแน่นอน (ไม่ต้องเขียน `if-else` ซ้อนกันพร่ำเพรื่อ)
    *   ตัวอย่างการนำมาแปลงตัวย่อภาษาอังกฤษเป็น Emoji ภาษาไทย:
        ```javascript
        switch (choice) {
            case 'rock': return '✊ ค้อน';
            case 'paper': return '✋ กระดาษ';
            case 'scissors': return '✌️ กรรไกร';
        }
        ```
*   **การวนลูป (for และ while loops)**:
    *   **for loop (รู้รอบแน่นอน)**: เปรียบเหมือน **"การวิ่งรอบสนามโรงเรียนตามจำนวนรอบที่ครูกำหนด"** นำมาใช้จัดการผูก Event Listener ให้กับปุ่มเป่ายิ้งฉุบทั้ง 3 ปุ่ม หรือใช้เซ็ตเปิด/ปิดการทำงานของปุ่มทุกปุ่มพร้อมกันโดยใช้โค้ดเพียงไม่กี่บรรทัด
    *   **while loop (ไม่รู้รอบแน่นอน)**: เปรียบเหมือน **"การวิ่งเก็บขยะไปเรื่อยๆ ตราบใดที่ยังเห็นขยะอยู่บนพื้น"** นิยมใช้เมื่อไม่ทราบจำนวนรอบที่ชัดเจน แต่จะทำงานซ้ำไปเรื่อยๆ จนกว่าเงื่อนไขจะเป็นเท็จ (เช่น สุ่มเลขใหม่เรื่อยๆ จนกว่าจะไม่ซ้ำกับของเดิม)

### 3. ⚡ ส่วนที่ 3: ฟังก์ชันการทำงาน (Regular vs Arrow Functions) (10 นาที)
*   **Regular Function (ฟังก์ชันแบบดั้งเดิม)**:
    *   ใช้คำสำคัญ `function` ประกาศ มักใช้กับฟังก์ชันประมวลผลขนาดใหญ่ที่มีการเรียกใช้ซ้ำ เช่น `function play(playerChoice) { ... }`
*   **Arrow Function (ฟังก์ชันแบบลูกศรย่อ)**:
    *   ใช้รูปแบบเครื่องหมายลูกศร `() => { ... }` มีขนาดกะทัดรัด นิยมใช้กับฟังก์ชันย่อยที่ไม่ได้มีความซับซ้อนมาก หรือใช้ส่งเป็น callback ในเหตุการณ์คลิกปุ่ม:
        ```javascript
        resetBtn.addEventListener('click', resetGame);
        btn.addEventListener('click', () => play(choices[i]));
        ```

### 4. 🧠 ส่วนที่ 4: กิจกรรมทดสอบความเข้าใจด่วน (Quick Quiz) (5 นาที)
1.  **คำถาม 1**: หากต้องการเข้าถึงค่า `'scissors'` จากอาเรย์ `const choices = ['rock', 'paper', 'scissors'];` จะต้องระบุดัชนี index อย่างไร? *(แนวตอบ: `choices[2]` เพราะดัชนีอ้างอิงเริ่มนับจากเลข 0)*
2.  **คำถาม 2**: ประโยชน์ที่สำคัญที่สุดของการนำ `for loop` มาใช้ในการจัดการปุ่มกดในเกมนี้คืออะไร? *(แนวตอบ: ช่วยลดความซ้ำซ้อนของโค้ด ไม่ต้องเขียนดึง ID และผูก Event Listener แยกรายปุ่มทีละ 3 รอบ)*
3.  **คำถาม 3**: การทำงานของ `while loop` แตกต่างจาก `for loop` ในแง่ใดชัดเจนที่สุด? *(แนวตอบ: for loop ใช้เมื่อรู้จำนวนรอบที่ชัดเจน เช่น ขนาดของ Array ส่วน while loop ใช้เมื่อต้องการให้รันซ้ำไปเรื่อยๆ จนกว่าเงื่อนไขจะเป็นเท็จ โดยไม่จำเป็นต้องระบุจำนวนรอบล่วงหน้า)*
