# สัปดาห์ที่ 12: โครงสร้างหลักและหน้าแรก (Layout & Index Page)

## กิจกรรมปฏิบัติ
[Project] หน้าแรกแพลตฟอร์มคอร์สเรียน (Index Page)

### งานที่ต้องทำ (Core)
* สร้างโครงสร้าง HTML พื้นฐาน และเชื่อมโยงไฟล์ `style.css`
* สร้างและจัดรูปแบบ Header (Navbar) ให้มีลิงก์เมนูครบถ้วน (Index, Course, Instructors, Contact Us) โดยใช้ Flexbox
* สร้างและจัดรูปแบบ Footer ด้านล่างสุดของเว็บ
* สร้างส่วน Hero Section แบ่งซ้ายขวา (ข้อความต้อนรับ และรูปภาพประกอบ)
* สร้างส่วนข้อความ "เปลี่ยนไอเดียให้เป็นผลงาน ก้าวสู่มืออาชีพ" โดยจัดกึ่งกลางและเน้นคำให้โดดเด่น

### งานเพิ่มเติม (Extra/Review)
* เพิ่มเอฟเฟกต์ (Hover effect) เมื่อนำเมาส์ไปชี้ที่ปุ่มหรือลิงก์เมนู ให้เปลี่ยนสีหรือมีเงา
