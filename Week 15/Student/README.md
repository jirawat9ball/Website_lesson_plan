# 🧑‍💻 สัปดาห์ที่ 15: หน้าโปรไฟล์ผู้สอนและการประกอบร่างเว็บไซต์ (Instructors Page & Site Assembly)

ยินดีต้อนรับสู่สัปดาห์ที่ 15! ในสัปดาห์นี้ เราจะสร้าง **"ห้องสุดท้ายของเว็บไซต์"** นั่นคือหน้าข้อมูลผู้สอน (Instructors) พร้อมทั้งนำทั้ง 4 หน้าที่เราสร้างมาตลอดทั้งเทอมมาเชื่อมต่อกันเป็นเว็บไซต์ที่สมบูรณ์ 100%!

---

## 🎯 วัตถุประสงค์การเรียนรู้
1. รู้วิธีเปลี่ยนรูปภาพธรรมดาให้เป็น **"วงกลมสมบูรณ์แบบ (Circular Avatar)"** ด้วย `border-radius: 50%` และ `object-fit: cover`
2. จัดระเบียบไอคอนโปรแกรม/ทักษะด้วย **Flexbox (`display: flex`, `flex-wrap: wrap`, `gap`)**
3. รู้วิธีจัดระเบียบไฟล์รูปภาพเข้าสู่โฟลเดอร์ `images/` (Asset Management) และแก้ไข Path ได้อย่างถูกต้อง
4. เชื่อมโยงเมนูนำทาง (Navigation Bar) ของทั้ง 4 หน้าให้คลิกสลับไปมาได้อย่างสมบูรณ์แบบโดยไม่มีหน้า 404

---

## 📁 ขั้นตอนการลงมือปฏิบัติ (Step-by-Step Guide)

### 🔹 ขั้นตอนที่ 1: จัดระเบียบไฟล์รูปภาพ (Asset Management)
1. ในโฟลเดอร์โปรเจกต์ของตัวเอง ให้สร้างโฟลเดอร์ย่อยชื่อ `images`
2. ย้ายไฟล์รูปภาพทั้งหมดที่เคยใช้ในหน้า `index.html`, `course.html`, `contact.html` เข้าไปไว้ในโฟลเดอร์ `images/`
3. กลับไปตรวจโค้ดในหน้าเดิม ทุกจุดที่มีแท็ก `<img src="...">` ให้แก้ Path โดยเติม `images/` ข้างหน้า เช่น:
   ```html
   <!-- จากเดิม -->
   <img src="banner.jpg">
   <!-- เปลี่ยนเป็น -->
   <img src="images/banner.jpg">
   ```
4. ทดสอบเปิดหน้าเว็บเดิมดูว่ารูปภาพยังแสดงผลครบถ้วนหรือไม่

---

### 🔹 ขั้นตอนที่ 2: เริ่มต้นสร้างหน้า Instructors
นักเรียนสามารถเลือกฝึกปฏิบัติได้ตามความสะดวก:
* **แบบใช้ Bootstrap 5 (แนะนำสำหรับฝึก Utility & Grid):** เปิดไฟล์ `exercise_bootstrap.html` แล้วเติมคลาสของ Bootstrap เช่น `rounded-circle`, `col-lg-5`, `d-flex` ลงในช่องว่าง `___`
* **แบบสร้างด้วยตนเอง (Vanilla CSS):** เปิดไฟล์ `exercise.html` คู่กับ `style_exercise.css` หรือสร้างไฟล์ `instructors.html` และ `style.css` ขึ้นมาใหม่ด้วยตัวเอง

---

### 🔹 ขั้นตอนที่ 3: ตกแต่งรูปโปรไฟล์ให้เป็นวงกลม (Circular Avatar)
ในไฟล์ CSS ให้ใส่คุณสมบัติ 3 ตัวสำคัญนี้ที่รูปภาพผู้สอน:
```css
.instructor-profile img {
  width: 400px;         /* 1. กำหนดกว้าง-สูงให้เท่ากันเป็นสี่เหลี่ยมจัตุรัส */
  height: 400px;
  border-radius: 50%;   /* 2. สั่งโค้งมน 50% รอบด้านกลายเป็นวงกลม */
  object-fit: cover;    /* 3. จัดภาพให้เต็มกรอบโดยไม่บิดเบี้ยว */
}
```

---

### 🔹 ขั้นตอนที่ 4: จัดเรียงไอคอนโปรแกรม (Programs Grid)
สร้างแถวไอคอนโปรแกรมด้วย Flexbox:
```css
.programs {
  display: flex;
  flex-wrap: wrap;      /* ให้ไอคอนไหลลงมาบรรทัดใหม่เมื่อจอแคบ */
  gap: 15px;            /* เว้นระยะห่างระหว่างไอคอน */
}
```

---

### 🔹 ขั้นตอนที่ 5: ประกอบร่างและเชื่อมโยง 4 หน้าเว็บ (Site Assembly)
เปิดไฟล์ HTML ทั้ง 4 หน้า ได้แก่:
1. `index.html`
2. `course.html`
3. `contact.html`
4. `instructors.html`

ตรวจสอบแถบ Navbar ในแท็ก `<nav>` ให้มีลิงก์ตรงตามนี้:
```html
<a href="index.html">Index</a>
<a href="course.html">Course</a>
<a href="instructors.html">Instructors</a>
<a href="contact.html">Contact Us</a>
```
> **🌟 เคล็ดลับ:** หน้าไหนกำลังเปิดอยู่ ให้ใส่ `class="active"` ที่ลิงก์ของหน้านั้น เพื่อให้มีแถบขีดเส้นใต้สีน้ำเงินบอกตำแหน่ง เช่น ในไฟล์ `instructors.html` ให้ใส่ `<a href="instructors.html" class="active">Instructors</a>`

## 🚀 ความท้าทายพิเศษ (Extra Challenge)
สำหรับคนที่ทำส่วนหลักเสร็จแล้ว:
* **Micro-animation:** ใส่เอฟเฟกต์เด้งลอยเมื่อเอาเมาส์ชี้ที่กล่องไอคอน:
  ```css
  .icon-box:hover {
    transform: translateY(-5px);
    box-shadow: 0 8px 18px rgba(0, 123, 255, 0.25);
    transition: all 0.3s ease;
  }
  ```
* **Responsive Test:** ลองปรับขนาดหน้าจอในเบราว์เซอร์ให้แคบลง ตรวจดูว่ารูปและข้อความเรียงตัวเป็นแนวตั้งสวยงามหรือไม่
