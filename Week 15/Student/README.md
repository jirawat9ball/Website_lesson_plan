# สัปดาห์ที่ 15: หน้าโปรไฟล์ผู้สอนและการประกอบร่างเว็บ (Instructors Page & Site Assembly)

## กิจกรรมปฏิบัติ
[Project] หน้าผู้สอน และการจัดระเบียบโครงสร้างเว็บ

### งานที่ต้องทำ (Core)
* สร้างโฟลเดอร์ย่อยชื่อ `images` นำรูปภาพทั้งหมดที่มีไปใส่ไว้ และแก้ไขโค้ด `<img src="...">` ในทุกหน้าให้ดึงภาพมาแสดงได้อย่างถูกต้อง
* อัปเดตลิงก์ในแท็ก `<a>` ของเมนู Navbar ในทุกไฟล์ (index, course, contact) ให้สามารถคลิกสลับหน้าไปมาได้
* สร้างไฟล์ `instructors.html` และวาง Navbar / Footer ไว้ให้พร้อม
* แบ่งหน้าจอออกเป็น 2 ฝั่ง (ซ้าย-ขวา)
* ฝั่งซ้าย: ใส่ภาพผู้สอน (รูปตัวคุณเองหรือรูปตัวอย่าง) และใช้ CSS ทำให้ภาพเป็น "วงกลม" (`border-radius: 50%`)
* ฝั่งขวา: ใส่ชื่อ, คำบรรยาย, หัวข้อความชำนาญ (program) และจัดเรียงไอคอนโปรแกรมหลายๆ อันติดกันด้วย Flexbox

### งานเพิ่มเติม (Extra/Review)
* เพิ่มไฮไลต์ (ขีดเส้นใต้ หรือเปลี่ยนสีข้อความ) ที่เมนู Navbar เพื่อบอกผู้ใช้ว่าตอนนี้กำลังเปิดอยู่ที่หน้าไหน (Active State)
