# 📁 โฟลเดอร์สำหรับจัดเก็บรูปภาพ (Images Folder)

ให้นักเรียนนำไฟล์รูปภาพทั้งหมดที่ใช้ในเว็บไซต์ เช่น:
- รูปภาพหน้าแรก (Hero Banner / Illustration)
- รูปภาพหน้าคอร์ส (Course Thumbnails)
- รูปภาพโปรไฟล์ผู้สอน (Instructor Avatar)
- รูปภาพไอคอนโปรแกรมต่างๆ (HTML5, CSS3, JS ฯลฯ)

มาเก็บรวบรวมไว้ในโฟลเดอร์ `images/` นี้ เพื่อให้โครงสร้างโปรเจกต์สะอาดและเป็นระเบียบตามมาตรฐานสากล!
