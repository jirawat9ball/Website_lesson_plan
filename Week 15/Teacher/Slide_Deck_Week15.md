### Slide 3: ปูพื้นฐานความเข้าใจด้วยการเปรียบเทียบ (Theory & Analogy)

  * *เปรียบเทียบ:* เหมือน "การปั๊มเหรียญตรา" หรือ "การใช้มีดเจาะช่องกรอบรูปวงกลม"

* **2. การจัดระเบียบไฟล์รูปภาพ (Asset Management):**

  * *เปรียบเทียบ:* เหมือน "การเปิดประตูทะลุกันระหว่าง 4 ห้องในบ้านหลังใหญ่"

### Slide 4: สรุปคำสั่งและไวยากรณ์สำคัญ (Syntax & CSS Cheat Sheet)
* **ตัดรูปให้กลมและไม่เบี้ยว (Circular Image):**
  ```css
  img.profile {
    width: 300px;
    height: 300px;         /* กว้าง-สูงต้องเท่ากัน */
    border-radius: 50%;    /* มุมโค้งมน 50% กลายเป็นวงกลม */
    object-fit: cover;     /* คมชัด ไม่บิดเบี้ยว ไม่เสียสัดส่วน */
  }
  ```
* **จัดกลุ่มไอคอนแบบแถวยืดหยุ่น (Icon Grid with Flexbox):**
  ```css
  .programs {
    display: flex;
    flex-wrap: wrap;       /* ล้นขอบจอแล้วขึ้นบรรทัดใหม่ให้อัตโนมัติ */
    gap: 15px;             /* ระยะห่างระหว่างไอคอนแต่ละตัว */
  }
  ```
* **การระบุ Path ในโฟลเดอร์ (Relative Path):**
  ```html
  <!-- ดึงรูปจากโฟลเดอร์ย่อย images -->
  <img src="images/profile.jpg" alt="Teacher">
  <!-- ลิงก์เชื่อมโยงไปยังหน้าเว็บอื่นในโฟลเดอร์เดียวกัน -->
  <a href="instructors.html" class="active">Instructors</a>
  ```

### Slide 6: ก้าวแรกการตั้งค่าระบบ (Step 1: Setup & Asset Management)
1. เปิดโฟลเดอร์โปรเจกต์ใน VS Code
2. **สร้างโฟลเดอร์ใหม่:** ตั้งชื่อว่า `images`
3. ย้ายไฟล์รูปภาพทั้งหมดที่เคยใช้ในหน้า `index.html`, `course.html`, `contact.html` เข้าไปในโฟลเดอร์ `images/`
4. **จุดสำคัญ:** อย่าลืมตรวจเช็คและแก้โค้ด `<img src="...">` ในทุกหน้าให้เติม `images/...` นำหน้า!

### Slide 8: ปลดล็อกความท้าทายพิเศษ (Extra Challenge Details)
* **Level 1: Active Menu Highlight**
  * เพิ่มคลาส `.active` ในแท็ก `<a>` ของหน้าปัจจุบัน เพื่อให้มีขีดเส้นใต้สีน้ำเงินชัดเจน เช่น ใน `instructors.html`:
    `<a href="instructors.html" class="active">Instructors</a>`
* **Level 2: Icon Box Hover Micro-animation**
  * ใส่เอฟเฟกต์เด้งดึ๋งเมื่อชี้เมาส์ที่กล่องไอคอนโปรแกรม:
    ```css
    .icon-box:hover {
      transform: translateY(-5px);
      box-shadow: 0 8px 16px rgba(0,0,0,0.15);
      transition: all 0.3s ease;
    }
    ```

### Slide 9: จุดระวังและเทคนิคป้องกันบั๊ก (Common Bugs & Debugging)
* 🐞 **บั๊กที่ 1: รูปโปรไฟล์กลายเป็น "วงรีรูปไข่"**
  * *สาเหตุ:* รูปเดิมกว้างไม่เท่ากับสูง (ไม่ใช่สี่เหลี่ยมจัตุรัส 1:1)
  * *วิธีแก้:* กำหนดทั้ง `width` และ `height` ให้เท่ากัน และใส่ `object-fit: cover;`
* 🐞 **บั๊กที่ 2: รูปภาพไม่ขึ้น กลายเป็นรูปไอคอนแตก**
  * *สาเหตุ:* พิมพ์ Path ผิด เช่น ลืมพิมพ์ชื่อโฟลเดอร์ `images/` หรือตัวพิมพ์ใหญ่-เล็กของนามสกุลไฟล์ไม่ตรงกัน (`.JPG` vs `.jpg`)
* 🐞 **บั๊กที่ 3: คลิกลิงก์เมนูแล้วขึ้น Error 404 (Not Found)**
  * *สาเหตุ:* สะกดชื่อไฟล์ใน `href="..."` ผิด เช่น พิมพ์ `instructor.html` (ลืมตัว s) แต่ไฟล์จริงชื่อ `instructors.html`

### Slide 10: กิจกรรมแลกเปลี่ยนเรียนรู้ (The No-404 Broken Link Challenge)
* **กติกาภารกิจ:**

  3. เช็ครูปภาพทุกรูปว่าโหลดขึ้นครบ ไม่มีภาพแตก
  4. หากเจอจุดผิดพลาด ให้ช่วยกันบอกและแก้ไขทันที!
