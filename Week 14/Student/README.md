# สัปดาห์ที่ 14: ฟอร์มรับข้อมูลและหน้าติดต่อ (Forms & Contact Us Page)

## กิจกรรมปฏิบัติ
[Project] หน้าติดต่อเรา (Contact Us Page)

### งานที่ต้องทำ (Core)
* สร้างไฟล์ `contact.html` คัดลอกส่วน Navbar และ Footer มาให้พร้อม
* สร้างฟอร์มการติดต่อ (`<form>`) ที่ประกอบด้วยช่องรับข้อมูล 3 ช่อง:
  1. ช่องกรอกชื่อ (`<input type="text">`)
  2. ช่องกรอกอีเมล (`<input type="email">`)
  3. ช่องข้อความ (`<textarea>`)
* ใช้ CSS ตกแต่งฟอร์มให้สวยงาม (พื้นหลังเทาอ่อน, ไม่มีกรอบ, ขอบมน) 
* จัดช่องชื่อและอีเมลให้อยู่คู่กันในแนวนอน (ซ้าย-ขวา) 
* สร้างส่วนข้อมูลการติดต่อ (ไอคอน, ที่อยู่, เบอร์โทร, อีเมล) แบ่งเป็น 3 คอลัมน์ด้านล่าง 

### งานเพิ่มเติม (Extra/Review)
* ลองหาวิธีทำพื้นหลังส่วนข้อมูลการติดต่อด้านล่าง ให้มีครึ่งบนเป็นสีขาวและครึ่งล่างเป็นสีน้ำเงิน (ตามภาพตัวอย่าง) 
* เพิ่มปุ่ม "Submit" สวยๆ ใต้ช่อง Message
