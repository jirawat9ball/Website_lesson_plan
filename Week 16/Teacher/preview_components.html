สรุปสิ่งที่นักเรียนได้เรียนรู้จากส่วนนี้ (Key Takeaways)

Single Source of Truth

การเขียนเว็บที่ดีจะไม่คัดลอกโค้ดเดิมซ้ำๆ (DRY: Don't Repeat Yourself) การเก็บ Navbar ไว้ที่ components.js ช่วยให้แก้ไขจุดเดียวแล้วอัปเดตทั้งเว็บทันที

CSS Variables

การใช้ตัวแปร var(--brand-blue) ทำให้นักเรียนสามารถ Re-brand หรือสร้าง Dark Mode ได้ง่ายดายโดยการเปลี่ยนค่าตัวแปรใน CSS โดยไม่ต้องไล่แก้โค้ดทุกบรรทัด

Responsive Design

การทดสอบย่อ-ขยายหน้าจอมือถือ (Viewport Toggle) ช่วยให้นักเรียนเข้าใจว่า Navbar ของ Bootstrap จะยุบกลายเป็นปุ่ม Hamburger อัตโนมัติเมื่อหน้าจอแคบกว่า 992px
