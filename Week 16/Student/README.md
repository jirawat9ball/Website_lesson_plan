# สัปดาห์ที่ 16: การทดสอบคุณภาพและนำเว็บขึ้นระบบจริง (QA & Web Hosting)

## กิจกรรมปฏิบัติ
[Project] นำเว็บไซต์แพลตฟอร์มการเรียนรู้ 4 หน้าขึ้น GitHub Pages

### งานที่ต้องทำ (Core)
* ทำการทดสอบ QA (Quality Assurance) โดยกดตรวจสอบลิงก์เมนูทุกหน้า ว่าสามารถคลิกไป-กลับหากันได้สมบูรณ์ และไม่มี Error (Broken Link)
* ใช้เครื่องมือ Inspect > Device Toggle บนเบราว์เซอร์ เพื่อจำลองมุมมองมือถือ และปรับแก้โค้ด CSS เล็กๆ น้อยๆ หากพบว่ารูปภาพล้นขอบจอ
* สมัครสมาชิกและสร้าง Repository บน GitHub
* อัปโหลดไฟล์งานทั้งหมด (html 4 ไฟล์, style.css 1 ไฟล์ และโฟลเดอร์ images) ขึ้น GitHub
* ตั้งค่าเปิดใช้งาน GitHub Pages เพื่อเปลี่ยนโค้ดเป็นเว็บไซต์จริง
* ส่งลิงก์ผลงาน (URL) ที่เป็น `.github.io/...` ให้เพื่อนหรือคุณครูตรวจสอบ

### งานเพิ่มเติม (Extra/Review)
* ลองเปิดลิงก์เว็บไซต์ของตนเองผ่าน "สมาร์ตโฟน" จริงๆ แล้วดูว่าการแสดงผล หรือปุ่มกดต่างๆ ใช้งานสะดวกหรือไม่ (ทดสอบ UX บนอุปกรณ์จริง)
