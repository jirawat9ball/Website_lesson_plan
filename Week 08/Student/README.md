# สัปดาห์ที่ 8: CSS Grid Layout

## กิจกรรมปฏิบัติ
[Project] Classic Web Layout

### งานที่ต้องทำ (Core)
• สร้างหน้าเว็บที่มีโครงสร้างประกอบด้วย Header, Sidebar, Main Content, และ Footer 
• ใช้ CSS Grid ในการจัดวางคอลัมน์ โดยแบ่งคอลัมน์เป็น 1fr (Sidebar) และ 2fr (Main Content)
• กำหนดให้ Header และ Footer กินพื้นที่คลุมทั้ง 2 คอลัมน์

### งานเพิ่มเติม (Extra/Review)
• ปรับสีสัน จัดขนาดตัวอักษร 
• ลองเปลี่ยนสัดส่วนคอลัมน์เป็น 1fr 3fr ดูว่าหน้าเว็บเปลี่ยนไปอย่างไร
