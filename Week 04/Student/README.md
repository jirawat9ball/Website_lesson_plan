# สัปดาห์ที่ 4: Introduction to JavaScript

## กิจกรรมปฏิบัติ
**[Project] 2-Digit Lottery Simulator (โปรแกรมจำลองสลากกินแบ่งเลขท้าย 2 ตัว)**

โจทย์แล็บในสัปดาห์นี้จะให้ทุกเรียนเขียนคำสั่งควบคุมพฤติกรรมการทำงานหน้าเว็บ เพื่อสร้างระบบเสี่ยงดวงสุ่มตรวจสลากกินแบ่งเลขท้าย 2 ตัว โดยประยุกต์ใช้ความรู้จากบทเรียนทฤษฎีในชีวิตประจำวัน

---

### 1. โครงสร้างระบบไฟล์ปฏิบัติการ
ให้นักเรียนเปิดหาโฟลเดอร์ปฏิบัติการของสัปดาห์ที่ 4 ในโปรแกรม VS Code และตรวจสอบไฟล์ต่อไปนี้:
*   `index.html`: โครงร่างหน้าเว็บสำหรับกรอกข้อมูลและแสดงผล (มี Boilerplate และสไตล์เบื้องต้นเตรียมไว้ให้แล้ว)
*   `script.js`: ไฟล์สำหรับเขียนคำสั่ง JavaScript ควบคุมเงื่อนไขและการทำงาน

---

### 2. สิ่งที่ต้องทำในภารกิจหลัก (Core Mission - 10 คะแนน)
ให้นักเรียนเปิดไฟล์ `script.js` เพื่อเขียนโปรแกรมเสี่ยงตรวจสลากกินแบ่งเลขท้าย 2 ตัวตามสเต็ปดังนี้:
1.  **ดึง Element ของอินเทอร์เฟซ**: ใช้คำสั่ง `document.getElementById()` เพื่อดึงองค์ประกอบ HTML 4 ตัว ได้แก่:
    *   อินพุตช่องพิมพ์ตัวเลข (`#lotto-input`)
    *   ปุ่มกดตรวจรางวัล (`#play-btn`)
    *   พื้นที่แสดงผลเลขที่สุ่มได้ (`#winning-number`)
    *   พื้นที่แสดงข้อความผลลัพธ์ (`#result`)
2.  **เขียนฟังก์ชันรันการสุ่มและตรวจสอบ**:
    *   ดึงค่าตัวเลขจากอินพุตที่ผู้ใช้พิมพ์และแปลงให้เป็นจำนวนเต็มด้วย `parseInt()`
    *   สุ่มตัวเลขรางวัลเลขท้าย 2 ตัว (จำนวนเต็มตั้งแต่ 0 ถึง 99) โดยใช้คำสั่งทางคณิตศาสตร์สุ่ม: `Math.floor(Math.random() * 100)`
    *   อัปเดตข้อความเลขรางวัลที่สุ่มได้ในพื้นที่ `#winning-number` (เพื่อความสวยงาม กรณีได้เลขหลักเดียว เช่น `5` ให้แปลงและเติมเลขศูนย์นำหน้าให้แสดงเป็น `"05"` โดยใช้คำสั่ง `.toString().padStart(2, '0')`)
3.  **เปรียบเทียบผลลัพธ์เงื่อนไข**:
    *   ใช้โครงสร้าง `if-else` เช็คว่าตัวเลขที่นักเรียนซื้อ/ทาย ตรงกับเลขสุ่มรางวัลหรือไม่
    *   แสดงผลลัพธ์แจ้งเตือนใน `#result` เช่น `"🎉 ยินดีด้วย! คุณถูกรางวัลเลขท้าย 2 ตัว!"` (หากเลขตรงกัน) หรือ `"เสียใจด้วย! คุณไม่ถูกรางวัล"` (หากไม่ตรง)
4.  **เชื่อมโยงคำสั่งกับปุ่มกด**:
    *   ผูกฟังก์ชันการสุ่มตรวจรางวัลเข้ากับปุ่มกดผ่านเครื่องมือ `addEventListener` ดักฟังเหตุการณ์ `'click'`

### 3. สิ่งที่ต้องทำในภารกิจส่วนขยาย (Extra Challenge - +2 คะแนนเพิ่มพิเศษ)
1.  **ระบบตรวจรางวัลเฉียด (Near Miss)**: ดัดแปลงโครงสร้างเงื่อนไขโดยเพิ่มคำสั่ง `else if` เพื่อเช็คว่าตัวเลขที่ผู้ใช้ซื้อ คลาดเคลื่อนจากเลขที่สุ่มได้บวกหรือลบ 1 ค่าพอดีหรือไม่ (เช่น เลขรางวัลออก 55 แต่เราซื้อ 54 หรือ 56) ให้แสดงข้อความปลอบใจสีส้มว่า `"เฉียดไปนิดเดียว! เกือบถูกรางวัลแล้ว!"`
2.  **การคัดกรองข้อมูลนำเข้าที่ไม่ถูกต้อง (Validation)**: เขียนเงื่อนไข `if` ที่ส่วนบนสุดของฟังก์ชันเพื่อตรวจสอบว่า ผู้ใช้กรอกค่าว่างเปล่า หรือป้อนค่าตัวเลขหลุดช่วง `0 ถึง 99` หรือไม่ หากข้อมูลไม่ถูกต้อง ให้ขึ้นเตือนว่า `"กรุณากรอกตัวเลข 2 หลักให้ถูกต้อง (00-99)!"` เปลี่ยนข้อความสีส้ม และสั่งหยุดฟังก์ชันทันทีโดยใช้คำสั่ง `return`
