### 1. 🥤 ส่วนที่ 1: แนะนำ JavaScript และวิธีการเชื่อมโยงสคริปต์ (10 นาที)
*   **แนวทางการเปรียบเทียบ**:
    *   **HTML** คือ โครงตู้กดน้ำ, **CSS** คือ สีสันป้ายตกแต่งตู้น้ำ ส่วน **JavaScript** คือ **"ระบบประมวลผลและการตัดสินใจเบื้องหลังของตู้"**
*   **รูปแบบการเขียนและเชื่อมโยง JavaScript (สองวิธีหลัก)**:
    *   **1. แบบเขียนภายในหน้า HTML (Internal Script)**:
        *   ใช้แท็ก `<script>` ครอบโค้ด JS โดยตรงในไฟล์ HTML
        *   *ตัวอย่างการเขียน:*
            ```html
            <!-- index.html -->
            <button id="hello-btn">คลิก</button>
            <script>
                const helloBtn = document.getElementById('hello-btn');
                helloBtn.addEventListener('click', () => {
                    alert('สวัสดีจาก Internal Script!');
                });
            </script>
            ```
        *   *ข้อดี/ข้อเสีย:* สะดวก รวดเร็วสำหรับงานเล็กๆ แต่ทำให้ไฟล์ HTML รกและแชร์ข้ามหน้าเว็บอื่นไม่ได้
    *   **2. แบบแยกไฟล์ภายนอก (External Script - แนะนำ)**:
        *   เขียนโค้ด JS แยกเฉพาะในไฟล์นามสกุล `.js` (เช่น `script.js`) แล้วลิงก์เข้ามา
        *   *ตัวอย่างการเขียน:*
            ```html
            <!-- index.html -->
            <button id="hello-btn">คลิก</button>
            <script src="script.js"></script>
            ```
            ```javascript
            // script.js (ไม่ต้องมีแท็ก <script> ครอบ)
            const helloBtn = document.getElementById('hello-btn');
            helloBtn.addEventListener('click', () => {
                alert('สวัสดีจาก External Script!');
            });
            ```
        *   *ข้อดี:* โค้ดเป็นระเบียบ แยกโครงสร้างออกจากการควบคุมพฤติกรรมอย่างเป็นระบบ และแชร์ข้ามไฟล์ได้ง่าย

### 2. 📦 ส่วนที่ 2: ตัวแปรและประเภทข้อมูล (15 นาที) — *เทียบเท่าคลิป BorntoDev นาทีที่ 24:00 - 40:00*
*   **ตัวแปร (Variables)**: เปรียบเสมือน **"กล่องเก็บข้อมูลที่มีป้ายชื่อติดไว้"** เพื่อนำมาเรียกใช้หรือประมวลผลซ้ำ
    *   `let` (กล่องเปิดฝา เปลี่ยนของได้): เช่น ตัวแปรสำหรับคำนวณค่าน้ำหนัก ยอดเงินสะสม หรือคะแนนสะสม
    *   `const` (กล่องปิดตายด้วยกาวตราช้าง ห้ามเปลี่ยนค่า): เช่น พิกัดการดึงองค์ประกอบปุ่ม หรือค่าคงที่ทางคณิตศาสตร์
*   **ประเภทข้อมูลพื้นฐาน (Basic Data Types)**:
    *   `String` (ข้อความ): ครอบด้วยเครื่องหมายคำพูด เช่น `"Hello"`, `"50"`
    *   `Number` (ตัวเลขคณิตศาสตร์): ไม่มีเครื่องหมายคำพูด เช่น `50`, `1.85` (ใช้บวกลบคูณหารคำนวณได้จริง)
    *   `Boolean` (ค่าความจริง): มีสองสถานะคือ `true` (จริง) หรือ `false` (เท็จ)
*   **การตรวจสอบข้อมูลเบื้องหลัง (Debugging)**:
    *   ใช้ `console.log()` พ่นค่าออกทางหน้าหลังบ้าน (Inspect Console) เพื่อเช็กพฤติกรรมการประมวลผล
    *   ใช้ `alert()` แสดงหน้าต่าง Pop-up แจ้งเตือนด่วนบนจอภาพ
    *   *จุดเน้นย้ำเรื่องประเภทข้อมูล:* ฟังก์ชัน `parseFloat()` มีความสำคัญมากในการคัดกรองแปลงข้อมูลประเภทข้อความ (`String` เช่น `"50"`) ที่รับมาจากกล่อง Input บนหน้าเว็บ ให้กลายเป็นตัวเลขจุดทศนิยม (`Number` เช่น `50`) ก่อนทำการประมวลผลคำนวณ

### 3. 🔌 ส่วนที่ 3: ตัวดำเนินการและการประมวลผล (10 นาที) — *เทียบเท่าคลิป BorntoDev นาทีที่ 40:00 - 50:00*
*   **ตัวดำเนินการทางคณิตศาสตร์ (Arithmetic Operators)**:
    *   สัญลักษณ์คำนวณ: `+` (บวก), `-` (ลบ), `*` (คูณ), `/` (หาร)
    *   *ตัวอย่างการนำไปใช้:* `bmi = weight / (heightM * heightM)` (สูตรดัชนีมวลกาย)
*   **ตัวดำเนินการเปรียบเทียบ (Comparison Operators)**:
    *   เปรียบเทียบค่าสองฝั่งเพื่อส่งผลเป็นค่าความจริง (`true`/`false`):
    *   `>` (มากกว่า), `<` (น้อยกว่า), `>=` (มากกว่าหรือเท่ากับ), `<=` (น้อยกว่าหรือเท่ากับ), `==` (เท่ากับ)
*   **ตัวดำเนินการทางตรรกศาสตร์ (Logical Operators)**:
    *   `&&` (AND - และ): ต้องเป็นจริงทั้งสองฝั่งจึงจะได้ผลลัพธ์เป็นจริง (เช่น `bmi >= 18.5 && bmi <= 22.9`)
    *   `||` (OR - หรือ): ขอเพียงมีฝั่งใดฝั่งหนึ่งเป็นจริงก็ทำงานทันที
    *   `!` (NOT - ปฏิเสธ): กลับค่าความจริงจากจริงเป็นเท็จ หรือเท็จเป็นจริง

### 4. 🧠 ส่วนที่ 4: โครงสร้างควบคุมและตัดสินใจ (If-Else) (10 นาที) — *เทียบเท่าคลิป BorntoDev นาทีที่ 50:00 - 1:05:00*
*   **แนวคิดการตัดสินใจของเงื่อนไข (Conditionals)**:
    *   เปรียบเหมือนการคิดของตู้น้ำหยอดเหรียญ:
        *   **If (ถ้า)**: หยอดเหรียญครบ 20 บาท -> จ่ายน้ำกระป๋องโค้ก
        *   **Else If (หรือถ้า)**: หยอดเหรียญครบ 15 บาท -> จ่ายขวดน้ำเปล่า
        *   **Else (นอกเหนือจากนั้น)**: แจ้งเตือนสัญญาณไฟกระพริบว่าเงินสะสมไม่เพียงพอ
*   **ไวยากรณ์โครงสร้างควบคุมเงื่อนไข**:
    ```javascript
    if (เงื่อนไขที่ 1) {
        // สั่งทำงานเมื่อเงื่อนไขที่ 1 เป็นจริง
    } else if (เงื่อนไขย่อย) {
        // สั่งทำงานเมื่อเงื่อนไขย่อยเป็นจริง
    } else {
        // สั่งทำงานเมื่อไม่ตรงกับเงื่อนไขใดๆ ด้านบนเลย
    }
    ```
*   **กิจกรรมทบทวนด่วน (Quick Quiz) (5 นาที)**:
    1.  **คำถาม 1**: ทำไมเราต้องแปลงค่าน้ำหนักหรือส่วนสูงด้วยฟังก์ชัน `parseFloat()` ก่อนคำนวณทางคณิตศาสตร์? *(แนวตอบ: เพราะข้อความจากช่องอินพุตบนเบราเซอร์เป็นข้อมูลประเภท String หากไม่ทำการแปลงเป็นตัวเลขก่อน โค้ดจะไม่ประมวลผลคำนวณคณิตศาสตร์ และเกิดค่าผิดพลาดเป็น NaN หรือเอาข้อความมาต่อกัน)*
    2.  **คำถาม 2**: สัญลักษณ์ `&&` (และ) ทำหน้าที่อะไรในการเช็กเกณฑ์ BMI สุขภาพ? *(แนวตอบ: บังคับให้เงื่อนไขขนาบซ้ายและขวาต้องผ่านเกณฑ์ทั้งหมด เช่น ค่า BMI ต้องอยู่ตั้งแต่ 18.5 ขึ้นไป และไม่เกิน 22.9 จึงจะสรุปว่าเป็นเกณฑ์น้ำหนักปกติ)*
    3.  **คำถาม 3**: หากต้องการเขียนโค้ดตรวจสอบเงื่อนไข "ถ้าหยอดเงินสะสมน้อยกว่าราคาสินค้า ให้แสดง Alert บอกเงินไม่พอ" จะเขียนโครงสร้างได้อย่างไร? *(แนวตอบ: `if (money < price) { alert("ยอดเงินไม่พอ!"); }`)*

#### 2. ลุยภารกิจหลัก (Core Mission): สุ่มตรวจรางวัลเลขท้าย 2 ตัว (40 นาที | 10:55 - 11:35 น.)
*   **กิจกรรมของครู**:
    - **ขั้นตอนที่ 1 (ดึง Element)**: สอนดึงข้อมูลกล่องอินพุตตัวเลข ปุ่ม และพื้นที่แสดงผลจาก HTML มาเตรียมประมวลผลเป็นตัวแปรค่าคงที่ (`const`):
      ```javascript
      const lottoInput = document.getElementById('lotto-input');
      const playBtn = document.getElementById('play-btn');
      const winningNumDiv = document.getElementById('winning-number');
      ```

        ```javascript
        const formattedWinningNumber = winningNumber.toString().padStart(2, '0');
        ```

[Project] Simple 2-Digit Lottery Simulator (โปรแกรมจำลองสลากกินแบ่งเลขท้าย 2 ตัว)

### สิ่งที่ได้เรียนรู้:
1. การเชื่อมต่อลิงก์ภายนอกแบบ External JS และการดีบั๊กผ่าน `console.log()` / `alert()`
2. การสร้างตัวแปรเก็บข้อมูล และการแปลงประเภทข้อมูลตัวเลขจำนวนเต็มด้วย `parseInt()`
3. การสุ่มคำนวณทางคณิตศาสตร์ด้วย `Math.random()` และ `Math.floor()`
4. การสร้างเงื่อนไขควบคุมและเปรียบเทียบตรรกะแบบทางเลือกหลายเงื่อนไข (`if-else if-else`)
5. การดึง Element และอัปเดตอักษรสีสันบน DOM หน้าเว็บ (`innerText` / `style.color`)
